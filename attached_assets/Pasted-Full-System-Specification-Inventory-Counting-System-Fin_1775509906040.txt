🧹 INPUT SANITIZATION

Before ANY processing:

- Remove ALL leading non-alphanumeric characters

Example:
P0RJ6102C455 → 0RJ6102C455
]0RJ6102C455 → 0RJ6102C455

---

🧠 PARSING RULES

General principle:

- Extract CODE from the beginning
- Extract QUANTITY from the end
- Ignore everything in the middle (noise)

---

Supported formats

1. Code only

0RJ6701C455

→ define item (no quantity added)

---

2. Numeric only

2000

→ add quantity

---

3. Code;Quantity

0RJ6701C455;2000

---

4. Code;Quantity;Noise

0RJ6701C455;3000;WBAJSIDE43

→ ignore extra parts

---

5. Dot-separated

0RJ6701C455.WBAJSIDE433.2000

---

6. Long concatenated

COV37772001CN010934LG26023895010000200

---

7. Standard concatenated

0RJ6701C455YAI82HG002000

---

Code rule

- Default: first 11 characters
- Support shorter codes when necessary

---

🚨 EXCEPTION CODES

The following must be accepted exactly as they are:

624-087J
624-085D
624-087H
624-087B
624-087D
586-008B
6631R-G007H

---

Behavior

- Bypass parsing rules
- Treat as valid codes
- Do NOT attempt to extract quantity

---

🔒 SINGLE ITEM MODE

- First valid code defines CURRENT_ITEM
- Only that code is accepted
- All other codes are rejected

---

Table: counts

🔐 LOGIN SYSTEM

Behavior

- User must login before accessing system
- Validate username and password
- Deny access if invalid

---

🕒 SESSION SYSTEM

On login:

1. Check for existing active session

2. IF exists:
   
   - If last_update < 2 hours:
     → Ask: "Continue previous session?"
   - Else:
     → Mark old session as finished
     → Create new session

---

During use:

- Update last_update on every scan

---

On "Finalizar operação":

- Set status = finished
- Set end_time

---

🧠 COUNTING RULE

- All data must be linked to session_id
- NEVER mix sessions

---

📊 EXCEL

Import

- Upload file (ITEM | QUANTIDADE)

---

Comparison

- Compare ONLY with current session

---

Export

- Generate Excel file with session results

---

🕒 DATA RETENTION (30 DAYS)

Rule

- Keep data for 30 days

---

Cleanup

DELETE FROM sessions
WHERE start_time < datetime('now', '-30 days');

DELETE FROM counts
WHERE session_id NOT IN (SELECT id FROM sessions);
